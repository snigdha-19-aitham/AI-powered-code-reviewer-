# AI-Powered Code Reviewer  

A full-stack AI-powered code review application that integrates Google Generative AI to provide automated code feedback. The project features a React.js frontend with Prism.js syntax highlighting, a Node.js backend with Express.js, and supports Markdown rendering for enhanced readability.  

## Features  
- **AI-Powered Code Review**: Integrated Google Generative AI to analyze and provide feedback on code snippets.  
- **Modern Frontend**: Built using React.js with Vite for optimized performance and better development experience.  
- **Syntax Highlighting**: Implemented using Prism.js for improved code readability.  
- **REST API Integration**: Backend developed with Node.js and Express.js to handle AI requests.  
- **CORS & API Handling**: Added CORS support and Axios for seamless API communication.  
- **Markdown Support**: Enhanced code readability with Markdown rendering.
